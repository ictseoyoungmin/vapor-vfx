Vapor Direct WebGPU

Effects Studio

Choose a preset and load the GPU runtime.

Direct GPU field rendering. Fidelity mode uses a GPU optical-depth cache and low-order scattering approximation. No atlas packing, CPU snapshot, or texture upload during drawing. Temporal mode uses GPU-only optical history (static by default when selected). Choose renderer before Load. This example has no game-scene depth integration.

Snapshot is an explicit readback for diagnostics only. Hardware WebGPU required by default.
