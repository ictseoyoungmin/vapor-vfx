실제 VPF1 Float32 밀도·온도장을 읽어 Vapor의 JS CPU 광학 렌더러를 Web Worker에서 실행합니다. 영상의 배경 및 드론 합성은 이 뷰어에 포함되지 않습니다. 선택한 시점 사이의 실시간 유체 계산은 하지 않습니다. GPU 또는 Rust 실행 경로도 아닙니다. CPU 속도에 따라 렌더링 시간이 달라집니다.
