렌더링 및 구현 범위
연무
Python의 독립적인 국소 변형 밀도·온도장. 서로 다른 소산, 다중 스케일 침식과 연속적 좌표 변형을 사용한 예술적 VFX 근사.
광학
기존 Vapor 0.22 prepareFidelityVolume CPU 렌더러. Float32 밀도, 자기 그림자, 이방성 광산란, 내부 발광.
비교
이전 데모와 새 데모를 같은 재생 시간에 전환합니다. 카메라와 배경도 달라졌으므로 물리 알고리즘만을 통제한 실험은 아닙니다.
재생 방식
실제 3D 볼륨을 미리 렌더링한 영상. 화면 확대는 2D 확대입니다. 실시간 유체·파괴 시뮬레이션 또는 자유 카메라가 아닙니다.

네트워크 연결 없이 사용 가능합니다. 스페이스: 재생·정지, 좌우 방향키: 시간 이동, A/B: 이전판·개선판 전환. 무음 VFX 데모입니다.
