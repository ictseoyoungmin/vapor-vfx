# Current example assets

- `airborne-smoke/`: three actual Float32 artistic smoke fields and their SHA-256 manifest. This is a fictional rendered visual study, not blast physics.
- `field-assets/`: canonical cloud and terrain fog data from 0.21, with original metadata and preview images.
- `cloud-motion/`: 0.22 baked VPA1 cloud sequence.
- `cloud-hero/`: 0.22 high-resolution deformed cloud reference.

These files are optional data, not native runtime binaries. The full distribution includes them; source-only packages do not. Regenerated scratch outputs should stay in `reports/local/`. No historical report bundles are needed to run these current examples.
